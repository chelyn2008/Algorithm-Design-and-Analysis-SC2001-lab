# SC2001 — Algorithm Design and Analysis

A collection of laboratory projects completed for **SC2001: Algorithm Design and Analysis** at **Nanyang Technological University (NTU)**.

This repository documents the implementation and analysis of algorithms explored throughout the module. Each project applies theoretical concepts through code, experiments, and evaluation of algorithm performance.

## Learning Objectives

- Implement algorithms and understand how they work.
- Analyse time and space complexity.
- Compare theoretical expectations with experimental results.
- Evaluate the effects of input size, algorithm parameters, and implementation choices.
